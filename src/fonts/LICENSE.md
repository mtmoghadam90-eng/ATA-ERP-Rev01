# Vazirmatn

`Vazirmatn-Variable.woff2` is the Vazirmatn variable font, version 33.003, by
Saber Rastikerdar — https://github.com/rastikerdar/vazirmatn

Licensed under the SIL Open Font License, Version 1.1:
https://github.com/rastikerdar/vazirmatn/blob/master/OFL.txt

The OFL permits redistribution and embedding, including bundled in an
application, provided the font itself is not sold on its own and this notice
travels with it.

It is checked in rather than fetched from a CDN because this application runs
on an internal network: a browser that cannot reach fonts.googleapis.com used
to fall back to a system font, and the whole interface changed shape.
